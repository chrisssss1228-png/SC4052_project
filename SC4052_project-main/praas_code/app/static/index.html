1. Analyzer

Diagnoses the prompt on 7 dimensions.

2. Optimizer (TextGrad-style)

Produces a textual gradient, then applies it.

3. Multi-Model Adapter

Produces model-family-aware variants for Claude / GPT / Gemini styles.

4. Evaluator

Runs each variant and ranks outputs via LLM-as-judge with position-bias mitigation.
